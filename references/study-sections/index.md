Each folder contains:
- `panel.md`: scope, boundaries with neighboring panels, standing members, roster table with clusters, panel dynamics, fault lines, update log.
- `roster.json`: parsed roster (output of scripts/parse_roster.py), used for diffs when updating.
- `reviewers/<slug>.md`: one profile per member, built to references/profile-brief.md.

To add a section, follow references/update-guide.md ("Add a new study section") and add a row here.
